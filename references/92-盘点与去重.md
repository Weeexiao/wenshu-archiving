# 盘点源目录与去重

## 1. 源目录长什么样

办公室类部门的源目录通常是这样长出来的：

```
Z:\办公室\
├── 1.综合\01.文件管理\12.2025年发文（九建公司）\    ← 发文，每个文一个文件夹：243关于印发…的通知
│                        13.2025年收文（九建公司）\   ← 收文，同样 序号+题名
│      03.会议管理\03.总经理办公会\04.2025年\第N次总经理办公会\
│      08.档案管理\06.档案室\1  文书档案\2025年\      ← ⚠ 这是档案成果，不是源
├── 15.保密工作\2025\…     16.员工管理\…     19.信访工作\2025\…
├── 20.信息报送\2025\…     21.外审\…         24.内审\…      25.检查工作\2025\…
```

其他部门同理：`Z:\<部门>\…`，年度子文件夹多为 `2025` 或 `04.2025年` 这种写法。

**关键**：源目录里的 `08.档案管理\…\1  文书档案\` 是**归档成果**，绝对不能当源再扫一遍，否则会自己抄自己。

## 2. 盘点三步

### 第一步：按年度筛

只收**本年度**的材料。文件名带年份、或所在文件夹名带年份（`2025`、`04.2025年`）的才进候选。
往年材料一律排除，跨年度事项按**办结年度**。

### 第二步：按类型归类

| 目录特征 | 通常对应 |
|---|---|
| `12.2025年发文` / `13.2025年收文` 下的 `序号+题名` 文件夹 | 一条收发文 = 一个单元（收发文、文号都能直接取） |
| `会议管理\…\第N次总经理办公会\` | 一次会议 = 一个单元，内部多文件（议题、议案、记录、纪要） |
| `信访工作\2025\<日期>-<事由>\` | 一起信访 = 一个单元 |
| `保密工作\2025\…` | 责任书、统计表、检查材料，按"一次工作"合并 |
| `检查工作\2025\迎检资料\…` | 一次迎检 = 一个单元（内部按类别分子夹） |
| 单文件（xlsx/docx 台账、计划、总结） | 一个文件 = 一个单元 |

### 第三步：与已有目录去重

1. 把目录表三张子表里**本部门块**的所有行导出来（档号、文号、题名、日期）。
2. 按三级比对：
   - **文号完全相同** → 已入目录，跳过；
   - **题名高度相似**（去掉「关于」「的」「通知」后相同）→ 疑似已入，交用户确认；
   - **日期 + 事由都不同** → 新材料。
3. 台账/汇编类没有文号，靠「题名 + 年度」比对。

## 3. 起名：从源到单元

单元题名 = 源文件夹名（去掉前面的流水号）+ 必要的范围补充。

- 公文：直接用户名 `关于…的通知`。
- 会议：`2025年第N次总经理办公会会议材料（议题、议案、会议记录、纪要）`。
- 台账：`九建公司2025年信访台账`。
- 汇编：`2025年度综合管理检查迎检资料（决策会议、公文、会议…等13类）`。

**同一单元的关联件合并规则**：同一事由的正文、附件、批复、请示合一个单元；不同事由各自成单元。
合并后单元内文件数会明显变大（几十到几百个），这是正常的。

## 4. 常见"混装夹"（务必人工确认）

源目录里偶尔会有**没有流水号前缀**的文件夹，里面混着好几件事的文件（历史上临时拖拽留下的）。
判定特征：

- 文件夹名没有 `数字` 前缀，而同级的其他夹都有；
- 内部既有子文件夹又是散文件，且子文件夹各自属于不同收文；
- 子文件夹的修改时间分散在不同月份。

处置：**不要**按文件夹名整体建单元（会造成题名重复 + 混入无关文件）。拆开，按每个子文件夹各自的编号归位，散文件单独判。
