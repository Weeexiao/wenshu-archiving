# 安装与分享（给同事）

## 1. 装到自己的电脑

技能就是一个文件夹，放对位置即可：

```
C:\Users\<你的用户名>\.workbuddy\skills\wenshu-archiving\
├── SKILL.md
├── references\   （归档范围标准，按部门拆开）
├── scripts\      （盘点/复制/改名/自检）
└── assets\       （计划表与 bat 模板）
```

步骤：

1. 拿到 `wenshu-archiving.skill`（或同名 `.zip`），改后缀为 `.zip` 解压；
2. 把解压出的 `wenshu-archiving` 整个文件夹放进 `C:\Users\<用户名>\.workbuddy\skills\`；
3. 重开一个会话，输入「帮我归档 2025 年的文书档案」这类话，技能就会被唤起。

> 目录不存在就自己建一层 `.workbuddy\skills`。这是**用户级**技能，装一次对所有项目生效。

## 2. 第一次用之前

- 确认能访问档案共享（如 `Z:\`），并能打开目录表 xlsx；
- 跑一次自检看看基线：`python scripts/check_archive.py --root "<年度目录>"`；
- 如果 bash 里 `python` 不可用，用本机 Python 全路径，或在 bat 里按模板的查找顺序配置。

## 3. 同事之间怎么传

- 直接发 `.skill` / `.zip`（几百 KB，走邮箱或企业微信都行）；
- 不要发**解压后的散文件**，容易丢目录结构；
- 各人装各自的，互不影响；标准更新时整包替换即可（先删旧的同名文件夹）。

## 4. 标准更新了怎么办

归档范围/期限表如果有新版：

1. 把新版附件1 的对应章节内容，替换到 `references/0X-部门名.md`（只改该部门那份，别动其他部门）；
2. 档号规则、目录列定义变化时，改 `references/90-档号与目录规范.md`；
3. 改完重新打包分发，并在 `SKILL.md` 顶部注明版本日期。

> 一份文件只放一个部门的标准——这是本技能的设计前提，不要图省事合并成一个大文档。
