# 目录表、档号与格式规范

## 0. 没有现成目录表？用内置模板

`assets/档案目录模板.xlsx` 已按本规范建好（三张子表、前 3 行结构、10 列表头、格式、日期格式）。复制一份改成实际文件名后只需改三处：

1. 每张子表 A1 标题里的「XX公司20XX年」；
2. 档号示例里的单位代码（默认 SIGJ09，见第 2 节）；
3. 删除每表第 4 行的示例行（标了"此行照抄格式后可删除"）。

之后从 0001 起正常编号。

## 1. 目录表长什么样

文件一般是 `附件3：{公司}20XX年管理类档案目录.xlsx`，**三张子表**，按保管期限分：

| 子表 | 对应实体目录 |
|---|---|
| 永久 | `…\1  文书档案\20XX年\永久\` |
| 长期 | `…\20XX年\长期\` |
| 短期 | `…\20XX年\短期\` |

每张表前 3 行固定：

- 第 1 行：标题，如「九建公司2025年永久管理类档案目录」
- 第 2 行：统计行，格式 `共 X 个归档单元、Y 条文件记录，按归档机构和档号排序`
- 第 3 行：表头

表头 10 列：

| 列 | 名称 | 说明 |
|---|---|---|
| 1 | 序号 | **部门块内**连续编号，不是全表连续 |
| 2 | 档号 | `SIGJ09-GL-{年度}-{期限码}-{部门码}-{4位序号}` |
| 3 | 收发文 | 填「发文」/「收文」；台账、会议材料等非公文留空 |
| 4 | 文号 | 如 `九建公司办发〔2025〕243号`；非公文留空（不要填「—」） |
| 5 | 责任者 | 一般「九建公司」 |
| 6 | 题名 | 与实体文件夹名去掉序号后一致 |
| 7 | 日期 | 真实日期值，格式 `yyyy"年"m"月"d"日"` |
| 8 | 保管期限 | 永久 / 30年 / 10年 |
| 9 | 归档机构 | 部门全称，与实体文件夹名一致 |
| 10 | 永久表=归档路径；长期/短期=关联说明 | 路径末段就是 `序号-题名` |

## 2. 档号规则

```
SIGJ09-GL-2025-Y-BGS-0053
  │     │   │   │   │    └ 部门块内 4 位流水，按部门各自从 0001 起
  │     │   │   │   └──── 部门代码（见下表）
  │     │   │   └──────── 期限码：Y=永久，D30=30年，D10=10年
  │     │   └──────────── 档案年度（归档年度，不是成文年度）
  │     └──────────────── 管理类
  └────────────────────── 单位代码（九建公司）
```

| 归档机构（目录表/实体文件夹写法） | 部门代码 | 附件1 中的写法 |
|---|---|---|
| 办公室（党委办公室、党委工作部） | BGS | 办公室（党委办公室、党委工作部） |
| 人力资源部（党委组织部） | RLB | 人力资源部（党委组织部） |
| 财务资金部 | CWB | 财务资金部 |
| 审计监督部（纪委办公室） | SJB | 审计监督部(纪委办公室) |
| 经营管理部（法律合约部） | JYB | 经营管理部（法律合约部） |
| 生产管理部 | SCB | 生产管理部 |
| 物资设备部 | WZB | 物资装备部 |
| 安全环保管理部 | AQB | 安全环保管理部（应急管理办公室） |
| 技术质量部 | JSB | 技术质量部 |
| 市场开发部 | KFB | 市场开发部 |

> 部门的三种写法不一致是历史原因：**实体文件夹和目录表用上表左列**，附件1 用右列。追加时照抄目录表里已有的写法，不要"纠正"。

## 3. 追加行的铁律

1. **先读再写**：读该部门块最后一行，拿到序号、档号末 4 位、第 10 列写法，再决定新行。
2. **插块尾**：新行写在「本部门最后一行」与「下一个部门第一行」之间，**不要写到表尾**（部门按固定顺序分块）。
3. **序号接着编**：只在本部门块内 +1，不要全局重排。
4. **档号接着编**：只改最后 4 位流水，前缀一字不动。
5. **不动别人的行**：已有行（尤其是往年的）只读不改；确需修正先备份并单独说明。
6. **统计行同步**：追加后按实际总行数重算「共 X 个归档单元、Y 条文件记录」。
   - 归档单元 = 去重后的档号数
   - 文件记录 = 数据行数；一个单元内多行（关联件）会大于单元数
7. **格式对齐**：字体 10 号、水平+垂直居中、自动换行、行高照抄同表现有数据行、日期用日期格式。

## 4. 一个单元 vs 多条记录

- 一个档号 = 一个归档单元 = 实体上一个文件夹。
- 同一件事有多个文件（正文、附件、批复、关联请示）时，可以在**同一档号下写多行**（第 2 列档号重复），此时：
  - 单元数不变，文件记录数增加；
  - 长期/短期表第 10 列填「关联归档，共N件」；
  - 永久表第 10 列仍填同一单元的归档路径。
- 判断依据：是否是同一个「事由」。同一事由的多份文件合一个单元；不同事由各占一个单元。

## 5. 命名与摆放（实体）

```
…\1  文书档案\2025年\永久\办公室（党委办公室、党委工作部）\0053-九建公司2025年发文登记簿\
```

- 单元文件夹：`4位序号-题名`（`0053-`，**序号与题名之间有横杠**，2026 年起统一为此规则）。
- 单元内部：原始文件平铺，或按 `正文 / 附件 / 审批单` 分子文件夹。
- 关联件：单元内再按 `1-请示`、`2-批复` 这类子文件夹区分。
- 文件夹名里**不要出现** `/ \ : * ? " < > |`，题名过长时保留前 60 字左右并保证可辨识。
