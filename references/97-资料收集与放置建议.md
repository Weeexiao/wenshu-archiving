# 资料收集与放置建议（含发起指令示例）

> 目标：让用户用 5 分钟把资料准备到位，后面全流程顺畅；避免放在会让 agent「碰壁」的位置。

## 一、推荐做法：先集中，再归档

**建议用户把本年度要归档的资料集中复制到一个「收集夹」里**，再让 agent 开始。好处：

1. 一次扫描全覆盖，不漏项；
2. 候选清单干净，不用跨 20 个目录来回翻；
3. 混装夹、重复件检测更准；
4. 后面阶段 5 复制实体文件时源路径集中，脚本日志好核对。

**收集夹结构建议**（按归档范围的大类建子夹，和目录表的期限判定天然对应）：

```
D:\2025归档\办公室\          ← 收集夹（只放 2025 年要归的）
├─ 01-发文\                  ← 每份一个子夹：104关于印发《XX》的通知\正文.docx
├─ 02-收文\
├─ 03-会议管理\              ← 第1次总经理办公会\议题+记录+纪要
├─ 04-保密工作\
├─ 05-信访工作\
├─ 06-检查审计\
├─ 07-台账报表\
└─ 08-其他\
```

收集时的三条规矩：

- **只复制、不剪切**——归档确认完成前不要动原文件；
- **文件名保持原样**——不要批量重命名，题名和日期要从原文件名里取；
- **只放本年度的**——往年的、明显不在归档范围的（个人照片、软件安装包）不要混进来。

来不及集中也**可以先不集中**：把各个位置都告诉 agent，脚本支持多源扫描（见第 4 节指令示例 ②）。但集中是首选。

## 二、收集夹放哪？位置红绿灯

### ✅ 推荐

| 位置 | 理由 |
|---|---|
| **本地非系统盘**，如 `D:\2025归档\`、`E:\归档收集\` | 读写最快、权限最干净，agent 一定能操作 |
| **部门共享盘上自己有完全控制权限的目录**，如 `Z:\办公室\_2025归档收集\` | 归档实体本来就在共享盘，收集夹放同盘后面复制少跨盘 |

### ⚠️ 谨慎

| 位置 | 风险 |
|---|---|
| OneDrive / 网盘同步目录（夸克网盘、百度网盘同步夹） | 同步锁文件、路径超长（`\\?\` 前缀）会让复制和改名失败 |
| 共享盘上别人管理的目录 | 你有写权限但可能没有改名/删除权限，阶段 5 会卡壳 |
| 中文+空格+特殊字符很长的路径 | 能用，但出错概率上升；路径尽量短 |

### ❌ 不要放

| 位置 | 理由 |
|---|---|
| **桌面 / 下载文件夹** | 多数单位的安全软件（DLP）会拦截对这两个位置的批量读写；且桌面文件容易被清理、被同步策略接管 |
| 微信 / 企业微信的文件接收目录 | 文件名被自动改写加后缀，题名提取会失真 |
| U 盘 / 移动硬盘根目录 | 盘符会变（今天 E: 明天 F:），脚本里的路径会失效 |
| 系统盘中转（C:\Temp 之类） | 重装/清理即丢，且部分策略限制写入 |

> 一句话记住：**放在一个稳定的本地盘或自己有完全权限的共享盘目录，路径短、只放本年度、只复制不剪切。**

## 三、发起前的检查单（给用户的）

- [ ] 知道自己部门的全称（目录表里怎么写的，照抄那个）
- [ ] 明确归档年度
- [ ] 资料已集中到一个文件夹（或列好所有位置清单）
- [ ] 目录表路径（没有就说"没有"，用内置模板）
- [ ] 档案室实体根目录路径（第⑤步才用，先不知道也没关系）

## 四、发起指令示例（照抄即可，方括号里换成自己的）

**① 标准发起（资料已集中在收集夹）**

```
帮我归档 2025 年办公室的文书档案。
资料已集中在 D:\2025归档\办公室，
目录表用 C:\Users\张三\Desktop\附件3：九建公司2025年管理类档案目录.xlsx
```

**② 资料没集中，散在多个位置（把每个位置都列出来）**

```
帮我归档 2025 年办公室的文书档案。资料没集中，分散在：
- Z:\办公室\1.综合\01.文件管理
- Z:\办公室\15.保密工作
- Z:\办公室\19.信访工作
- D:\临时收集\2025年会议材料
目录表用附件3（桌面上的那份）。
```

**③ 第一次用，什么都没准备**

```
我是办公室的，第一次做文书档案归档，请引导我一步步来。
```
（agent 会按《95-首次使用指南》带你准备）

**④ 没有目录表，请用内置模板新建**

```
我们部门没有目录表，帮我用模板新建一份 2025 年的。
```

**⑤ 只想先盘点看看，还不想写表**

```
先只盘点 D:\2025归档\办公室 里 2025 年的候选材料，
列个清单给我确认，先不要写目录表。
```

**⑥ 中途补充归档（之前已经归过一批）**

```
上个月归过一批 2025 年办公室档案（目录表是附件3），
现在又收集到几份新材料，在 D:\补充材料\，帮我接着上次继续归。
```
（agent 会先去重，编号接着上次的续）

**⑦ 实体归档（目录写完之后）**

```
目录表确认无误，继续做实体归档，档案室根目录是
Z:\办公室\1.综合\08.档案管理\06.档案室\1  文书档案\2025年
```

**⑧ 归完自检**

```
帮我自检一下 2025 年的归档成果，目录表用附件3。
```

**⑨ 拿不准某份材料归不归 / 归多久**

```
《2025年食堂满意度调查结果》这类材料要归吗？归多久？
```
（agent 会按归档范围标准给出依据和选项，由你拍板）

## 五、agent 侧的引导要点（写给执行本技能的 agent）

1. 用户没说资料位置时，**先推荐"集中到收集夹"**，按第 1、2 节给建议；用户嫌麻烦再退到多源扫描。
2. 用户提供的位置在桌面/下载/网盘同步目录时，**主动提醒挪到本地盘或共享盘自己的目录**，并说明原因（安全策略拦截、同步锁）。
3. 指令里信息不全时，按四要素（部门/年度/位置/目录表）逐项问，一次 AskUserQuestion 问完，不要挤牙膏。
4. 用户贴出的路径先验证存在，再开扫；不存在立即指出而不是闷头报错。
