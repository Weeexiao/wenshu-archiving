# 保管期限判定

## 1. 三个期限档

| 档 | 含义 | 典型材料 |
|---|---|---|
| 永久 | 反映本公司主要职能活动和基本历史面貌、需长久查考 | 制度办法、年度计划总结、董事会/总经理办公会材料、登记簿、重要请示批复、重大信访、荣誉（省部级以上）、声像资料 |
| 30 年（长期） | 在较长时间内需要查考 | 一般性业务文件、非重大信访、年度以下的专项材料、台账、培训、检查整改、保密责任书 |
| 10 年（短期） | 短期内需要查考 | 事务性通知（放假、通讯录、车辆保险、伙食标准）、一般性会议材料、无批复的一般事项、简报动态 |

## 2. 判定顺序（照这个顺序走，别跳）

1. **先查本部门专用范围**：`0X-部门名.md`，业务职能对得上就按那一行。
2. **再查通用范围**：`01-通用归档范围.md`（会议、对上/对下业务、其他工作 17 类）。
3. **都对不上**：按「事由重要性」判，并在提交用户确认时明确说明是推定。

> 专用范围与通用范围冲突时，**以专用范围为准**（专用更贴合该部门业务）。

## 3. 汇总行与下级条目

附件1 里「保管期限」为空的行是**汇总行**（如 `2 对上业务 | 上级机关制发的…文件材料 |`），期限看它的下级条目（2.1 / 2.2 / 2.3）。
**不要**给汇总行直接套一个期限，要落到具体下级条目上。

## 4. 容易判错的六种情形

| 情形 | 判法 |
|---|---|
| 会议材料 | 全套（手册、议程、议题、名单、记录、纪要、讲话、决议）→ 永久；专题/交流材料、简报 → 30年；一般汇报材料、讨论未通过的 → 10年 |
| 信访 | **重大**信访（群体访、涉及金额大、上级督办、有领导批示）→ 永久；非重大 → 30年；信访工作计划 → 30年；信访总结、分析报告 → 永久 |
| 请示/批复 | 涉及重要事项（改制、机构、人事任免、大额资金）→ 永久；一般事项 → 30年；无批复的一般事项 → 10年 |
| 计划/总结 | 年度及以上 → 永久；年度以下的专项计划、总结 → 30年 |
| 荣誉 | 省部级及以上 → 永久；省部级以下（不含本公司颁发）→ 30年 |
| 台账/登记簿 | 收文登记簿、发文登记簿、用印审批表 → 永久；业务台账跟随其业务条目的期限；纯事务性台账（通讯补助、保险）→ 10年 |

## 5. 两个必须问用户的情形

1. **无法确定重要性**（如某次检查、某次来访的分量）——不要自己拍，列出来问。
2. **同一事由跨年度**——问清按哪一年归档（一般按**办结年度**）。

## 6. 日期怎么填

- 公文：用**成文日期**（落款日期），不是收文日期。
- 会议材料：用**会议召开日期**。
- 年度性台账/汇编/清单：用 **12 月 31 日**（或实际编制完成日，并在说明里注明）。
- 同一单元的关联件：用主件日期。
