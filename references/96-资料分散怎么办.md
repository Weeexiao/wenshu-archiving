# 资料分散怎么办（收集与多源盘点）

> 现实里资料很少乖乖待在一个文件夹：收发文在「01.文件管理」，会议纪要在「03.会议管理」，信访在「19.信访工作」……本文件给三种典型情形的处理方案。**原则：首选引导用户集中到收集夹（放哪、怎么建见 `97-资料收集与放置建议.md`）；用户不愿集中时再多源扫描，不折腾用户搬文件。**

## 情形 A：资料散在同一个部门盘的多个业务子夹（最常见）

比如 `Z:\办公室` 下有 20 多个专题夹，2025 年的材料分散在「15.保密工作\2025」「19.信访工作\2025」「1.综合\03.会议管理\…\2025年」……

**做法：多源扫描，不搬文件。**

```bash
python scripts/scan_source.py --src "Z:\办公室\1.综合" --src "Z:\办公室\15.保密工作" --src "Z:\办公室\19.信访工作" --year 2025
```

- `--src` 可以反复给，也可以一次给多个；每个源独立扫描，输出合并清单（带「源」列）。
- 混装夹、年度过滤照常生效；档案成果目录（08.档案管理）自动跳过。
- 盘完后向用户确认：「还有没有别的位置？桌面、邮箱、OA 待办里有没有？」**常见的遗漏位置**：个人桌面、下载文件夹、微信/企业微信接收的文件、OA 系统未归档件。

**什么时候才需要先集中？** 只有当一个源目录大到脚本扫不动（数万文件）或用户明确要求「先整理再归档」时，才让用户把本年度材料复制到一个临时收集夹（如 `Z:\办公室\_2025归档收集`）。复制完把收集夹路径当唯一 `--src` 传进来。**收集夹只复制、不剪切**，归档确认完成前不要动原文件。

## 情形 B：资料散在多人/多个项目手里

各项目、各部门经手人各存一份。处理顺序：

1. **列清单找人来要**：让 agent 按归档范围标准生成一张「应收材料清单」（哪类文件、找谁要、什么格式），发给各经手人。
2. **建一个收集夹收口**：如 `\\共享\2025归档收集\提交人姓名\`，每人一个子夹，避免互相覆盖。
3. **收齐后统一盘点**：收集夹作为 `--src`，脚本会正常出清单；混装夹检测此时特别有用——各人提交习惯不同，最容易混。
4. **去重**：同一份文件多人提交时，按「文号 → 题名 → 文件大小」比对，保留最完整的一份，其余记入「重复件清单」随收尾报告说明。

## 情形 C：只有纸质件，没有电子版

1. 先扫描（300dpi、PDF，多页合并成一个 PDF），命名 = 题名。
2. 电子扫描件按正常流程归档；纸质原件放档案盒并在目录表第 10 列或备注注明「仅纸质件，存档案盒X」。
3. **不要建空单元等扫描**：扫描件没到位前，该单元先不进目录，进了目录没文件自检会报空单元。

## 盘点完成的自查三问

向用户汇报前，先问自己：

1. **有没有漏源？** —— 让用户亲口确认「就这些位置了」，不要自己替他判断。
2. **有没有年份混进来？** —— 清单里抽查几条修改时间，确认没有 2024/2026 的混入。
3. **有没有明显的重复/混装？** —— 混装夹标记、同名不同夹、同名同文号，逐个点出来。
