# 首次使用指南（新手 3 分钟上手）

> 给第一次用本技能的同事。看完这一页就知道：跟 agent 说什么、要准备什么、它会带你走哪几步。

## 〇、安装后第一次对话怎么开口（agent 请照此引导）

用户如果说（README 里教的）：

```
帮我安装这个 skill：https://github.com/Weeexiao/wenshu-archiving，
安装完成后进入新手指引，我是第一次用。
```

说明技能已装好，agent 直接按下面的顺序开场（不要重复讲安装）：

1. **一句话自我介绍**：「我是文书档案归档助手，带你走 6 步：盘点→判定→写目录→归实体→自检，每步都会先问你。」
2. **发一张「发起前检查单」**（见《97-资料收集与放置建议.md》第 3 节）：部门全称、年度、资料位置、目录表、档案室根目录。
3. **用 AskUserQuestion 问四要素**（已知项不重复问），其中「资料位置」按 97 号文件的建议先引导集中到收集夹（提醒别放桌面/下载/网盘同步目录）。
4. 四要素齐了 → 直接进阶段 1，正常走流程；用户中途说「先不弄了」→ 把检查单原文留给用户下次接着说。

> 新手指引用户最常见的状态是「四要素只说得出部门和年度」——不要卡住，缺什么按 97 号文件的示例引导他补什么。

## 一、你只需要准备两样东西

| 东西 | 是什么 | 没有怎么办 |
|---|---|---|
| **待归档的资料** | 今年形成的电子文件所在的文件夹 | 见《96-资料分散怎么办.md》，散在多处也能办 |
| **归档范围标准** | 本公司的《文件材料归档范围和保管期限表》（docx/pdf 都行） | 本技能内置了九建公司 2025 版标准，直接用；其他单位请提供自己的 |

**目录表不用准备**——技能自带空白模板（`assets/档案目录模板.xlsx`），会自动帮你建好；如果部门已经有沿用多年的目录表（如「附件3」），把路径给 agent 沿用即可。

## 二、怎么发起

对 agent 说一句话就行，四要素说全了它会直接开干，说不全它会问你：

```
帮我归档 2025 年办公室的文书档案，资料在 Z:\办公室，
目录表用 C:\Users\XX\Desktop\附件3：….xlsx
```

四要素 = **部门 + 年度 + 资料位置 + 目录表**。第一次用说不全没关系，它会一个一个问。

## 三、它会带你走的六步

```
① 摸底   →  问清四要素（部门/年度/资料在哪/目录表在哪）
② 盘点   →  扫描资料，列出候选清单，找出「混装夹」「重复件」
③ 判定   →  每批 8~10 条问你：归不归？归多久？叫什么名？
④ 写目录 →  自动续编号写进目录表（写前备份）
⑤ 归实体 →  生成一键脚本，你双击，文件按规范摆进档案室
⑥ 自检   →  数量对账、查空单元、查重名，出收尾报告
```

每一步结束它都会停下来跟你确认，**不会不打招呼就改你的表**。

## 四、第一次用最常问的四个问题

**Q1：资料没有集中放在一个文件夹？**
→ 最省事的办法是先花 5 分钟集中复制到一个收集夹（怎么建夹、放哪最合适、什么位置不能放，见《97-资料收集与放置建议.md》）；来不及集中就把每个位置告诉 agent，脚本支持多源扫描（见《96-资料分散怎么办.md》）。

**Q2：我没有目录表，也没有档案室目录结构？**
→ agent 会用内置模板 `assets/档案目录模板.xlsx` 帮你新建一份，档号从 0001 起编。实体目录结构（`年度\期限\部门\序号-题名`）它会在第⑤步自动创建。

**Q3：网上共享盘提示拒绝访问、复制不动？**
→ 大概率是权限问题，不是你操作错了。agent 会把操作打包成 `.bat`，你双击运行即可（用它自己的登录身份跑）。详见《93-常见问题与坑.md》第 1 节。

**Q4：指令该怎么写？有没有现成的说法？**
→ 有。九种常见场景的发起指令示例都在《97-资料收集与放置建议.md》第 4 节，照抄替换方括号里的内容即可。

## 五、给管理员的建议（第一次部署）

1. 把技能包解压到每个使用者的 `C:\Users\<用户名>\.workbuddy\skills\`（见《94-安装与分享.md》）。
2. 如果贵单位不是九建公司，先替换 `references/01~11` 里的归档范围标准（每个部门一个文件，改哪份都不会影响别的部门）。
3. 用一批往年真实资料试跑一遍**阶段②③**（只盘点不写表），核对判定结果后再放开阶段④⑤。
