# 常见问题与坑

## 1. 网络共享的权限：能读能建，但不能改名和删除

现场表现（Windows + SMB 映射盘，如 `Z:` = `\\10.15.168.10\九公司`）：

| 操作 | 工具进程能不能做 |
|---|---|
| 列目录、读属性 | 能 |
| 新建子文件夹、写文件 | 能 |
| **打开文件读内容**（openpyxl / Get-FileHash） | **经常被拒**（Permission denied） |
| **对已存在文件夹改名、删除** | **不能**（`Permission denied`） |

原因不是目录设了只读，而是共享端按**登录会话凭据**授权：用户本人资源管理器里能改名，工具进程用的是受限令牌，拿不到那份凭据。

**处置原则**：凡涉及"读文件内容 / 改名 / 删除"，不要让工具硬试，改成**生成脚本 + 用户双击执行**：

```
脚本放本地（如 F:\...\），bat 里用全路径 python + "%HERE%xxx.py"，末尾 pause
bat 一律纯 ASCII 注释（cmd 按 ANSI 读，中文注释会拆坏命令行）
脚本里打印中文前先 sys.stdout.reconfigure(encoding="utf-8", errors="replace")
```

## 2. 两个目录表副本必须同步

档案室那份 `…\2025年\九建公司2025年管理类档案目录.xlsx` 和桌面上/办公室那份 `附件3：…xlsx` 是**两份实体**。
每次改完都要同步，否则下次有人拿旧版对账会炸。

## 3. 空单元 = 归档不完整

一个单元文件夹里 0 个文件，检查时就是"归档不完整"。

- 建单元前先确认源文件存在、非空；
- 归档后跑一次校验，列出所有 0 文件的单元；
- 真没有电子正文的（源文件夹被标了「（无）」），**不要建空单元**，改为补扫描件或在目录备注"仅纸质件"。

## 4. 重名单元要查根因，别直接删

同名单元往往是源目录里存在**重复/混装文件夹**（见 `92-盘点与去重.md` 第 4 节）。
处置顺序：

1. 比对两个单元内部文件（名称、大小、张数）；
2. 找出"有独有内容"的那个保留；
3. 无独有内容的整单元删除，目录行同步删除；
4. **档号不重排**（档案号一经使用不复用，留空号是规范做法）。

## 5. Excel 表格被占用

- 目标 xlsx 若正在编辑器/Excel 中打开，脚本保存会失败 → 先提示用户关闭，或用本地编辑器接口保存。
- 改之前先 `copy2` 一份 `…_改名前备份.xlsx`，出问题能回退。
- 合并单元格很多的老表，**不要整表重写**，只按行列坐标改单元格。

## 6. 编码与长路径

- 中文路径 + `\\?\` 前缀在网络映射盘上会直接 `Permission denied`，**不要加长路径前缀**。
- 文件名超过 200 字符时先截断题名（保留 60 字左右 + 事由关键词）。
- 文件名禁止 `/ \ : * ? " < > |`，题名里的书名号《》可以保留。

## 7. 归档前自检清单

- [ ] 年度对不对（只收本年度、按办结年度）
- [ ] 部门块定位对不对（序号、档号末位、第 10 列写法都读过）
- [ ] 每条都有期限、有日期、有题名
- [ ] 收发文/文号：公文必填，非公文留空
- [ ] 统计行数字重算过
- [ ] 实体单元数与目录单元数一致
- [ ] 无 0 文件单元、无同名单元
- [ ] 两份目录表副本一致
