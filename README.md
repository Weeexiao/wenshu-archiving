# 文书档案归档助手

面向日常管理类文书档案，按部门范围完成资料盘点、期限判定、三表目录编制、复制归位和自检。内置九建公司2025版范围，其他单位应替换对应制度与代码。本技能不处理建设项目六表三级目录。

## 使用

把整个技能文件夹放入Agent的技能目录，提供部门、归档年度、资料位置和现有目录表（没有也可新建）。例如：

> 整理2026年办公室文书档案，材料在D:\待归档，目录表用现有附件3，成果放D:\档案成果。保留原件，拿不准的单列。

支持WorkBuddy、Codex等可读取SKILL.md、执行本地Python及编辑表格的Agent。Python 3.11+，目录对账需openpyxl，按scripts/requirements.txt准备。Agent负责档案判断与表格编制；脚本不会仅凭关键词自动决定期限。

首次运行 `python scripts/restore_resources.py` 从内置文本资源还原三表Excel模板。无需外部模板下载。所有业务资源随包携带，发布包只含文本文件，避免SkillHub跳过Excel导致模板缺失。

## 1.1.0优化

- 合并重复说明，取消逐阶段反复审批，只确认缺项和实际歧义。
- 年份不明材料保留待核对；重复--src正确合并，成果目录可明确排除。
- 复制前整批校验路径、空源、重复编号和同名异内容；同内容重复运行跳过并校验哈希。
- 目录与实体按期限、部门、序号逐项对账，修复实体为零却漏报、依赖缺失却宣称通过的问题。
- 责任者按实际出具单位，未知日期不猜填；保留原表格式与人工修改，编号接续最大已用流水。
