# wenshu-archiving · 文书档案归档技能

WorkBuddy 技能包：一步步带你完成**文书档案归档全流程**——判断该不该归 → 归多久 → 怎么编号 → 怎么写目录 → 实体怎么摆 → 怎么自检。

## ✨ 特性

- **交互式推进**：每个阶段结束都会停下来和你确认，不打招呼绝不改你的表
- **按部门拆分标准**：归档范围按 10 个部门各一份文件拆开，只加载你所在部门的标准，不跨部门套用
- **内置目录表模板**：没有目录表也能直接开始，档号从 0001 起编
- **4 个实测脚本**：多源盘点（支持 `--src` 多目录、混装夹识别）、实体复制（plan.csv 驱动、可重复运行）、批量改名、成果自检（数量对账/空单元/同名单元）
- **新手友好**：首次使用引导、资料收集与放置建议（放哪、不能放哪）、九种场景的发起指令示例

## 📦 安装

### 方式一：WorkBuddy 内一键安装（推荐）

在 WorkBuddy 对话中说：

```
帮我安装这个 skill：https://github.com/Weeexiao/wenshu-archiving
```

### 方式二：手动安装

把本仓库克隆（或下载解压）到你的用户技能目录：

```powershell
git clone https://github.com/Weeexiao/wenshu-archiving.git "$env:USERPROFILE\.workbuddy\skills\wenshu-archiving"
```

安装完成后新开一个 WorkBuddy 会话即可生效。

## 🚀 快速开始

对 WorkBuddy 说一句话（四要素：部门 + 年度 + 资料位置 + 目录表）：

```
帮我归档 2025 年办公室的文书档案。
资料已集中在 D:\2025归档\办公室，
目录表用 C:\Users\张三\Desktop\附件3：九建公司2025年管理类档案目录.xlsx
```

说不全没关系，技能会一个一个问你。更多场景（资料散在多处、多人收集、纸质件、中途补充归档、只盘点不写表……）的指令示例见 [`references/97-资料收集与放置建议.md`](references/97-资料收集与放置建议.md) 第 4 节。

## 🗂 目录结构

```
SKILL.md                          # 主流程：六阶段流水线 + 硬性规则
references/
├─ 01-通用归档范围.md              # 所有部门适用（17 类）
├─ 02~11-*.md                     # 10 个部门的专用归档范围（每部门一份）
├─ 90-档号与目录规范.md            # 档号规则、目录表 10 列、追加铁律
├─ 91-保管期限判定.md              # 期限判定规则与易错情形
├─ 92-盘点与去重.md                # 盘点归堆与三级去重
├─ 93-常见问题与坑.md              # 权限/空单元/重名/Excel 占用
├─ 94-安装与分享.md                # 安装部署说明
├─ 95-首次使用指南.md              # 新手 3 分钟上手
├─ 96-资料分散怎么办.md            # 多源扫描/多人收集/纸质件
└─ 97-资料收集与放置建议.md        # 收集夹怎么建、放哪、指令示例
scripts/
├─ scan_source.py                  # 盘点源目录（多源、混装夹标记）
├─ copy_units.py                   # 按 plan.csv 复制归档单元
├─ rename_units.py                 # 批量加/去横杠改名
└─ check_archive.py                # 自检对账
assets/
├─ 档案目录模板.xlsx               # 三表目录模板（格式预设，开箱即用）
├─ plan_template.csv               # 实体复制计划模板
└─ run_script.bat.template         # 一键双击脚本模板
```

## ⚙️ 适配你自己的单位

本技能内置的是九建公司 2025 版归档范围标准。其他单位使用时替换 `references/01~11` 里的标准文件即可（每个部门一个文件，互不影响），并按 `references/90-档号与目录规范.md` 调整档号中的单位代码（默认 `SIGJ09`）与部门代码表。
